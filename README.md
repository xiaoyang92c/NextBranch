# 下一枝 NEXT BRANCH

农科村枝条邮局的交互式前端原型。建议在项目目录运行 `python -m http.server 4173 --directory dist`，然后访问 `http://localhost:4173/`。

## Vercel 配置

这是一个原生 HTML、CSS、JavaScript 静态网站，首页位于 `dist/index.html`，不使用 Vite，也没有第三方 npm 依赖。`dist` 是网站源文件目录，需要保留在 Git 中。

在仓库根目录执行 `npm ci`，再执行 `npm run build`。构建脚本检查首页引用、JavaScript 语法、相对模块引用及静态文件完整性，直接使用现有 `dist` 文件，不打包或重写页面。

仓库根目录的 `vercel.json` 明确设置 Framework 为 Other（`null`）、Install Command 为 `npm ci`、Build Command 为 `npm run build`、Output Directory 为 `dist`，覆盖控制台中错误的 `vite build`。Vercel 项目的 Root Directory 应保持仓库根目录（留空），不能设为 `dist`。`package.json`、`package-lock.json`、`vercel.json` 和 `scripts/` 位于同一根目录，配置推送到 GitHub 后由关联的 Vercel 项目自动重新部署。

## 演示流程

主导航包含「邮票馆、枝条放映室、枝友来信」三个章节。邮票馆采用整屏斜向邮票展台：拖动或滚轮可沿斜向轨迹切换邮票，轻触中央邮票直接打开枝条档案。滑动中切换章节时冻结文字轨道与邮票的实际位置再退出，避免取消动画后两份文字回到同一基线。中央邮票留在原位，用交错笔刷逐行涂抹出完整印面，投影随后轻轻伸展；两侧保持完全不透明，从画布外延后滑入，标题提前逐字显墨，完成后保持完整墨色。领取作为植物资料的二级流程，不再提供单独的领取展馆。完整路径为：邮票馆 → 枝条档案 → 接收这一枝 → 枝条邮单 → 模拟现场领取 → 枝条放映室 → 生长明信片。旧的领取展馆地址会自动回到邮票馆。枝友来信支持浏览、提问和枝友回复。内容保存在当前浏览器的 `localStorage` 中，没有接入真实库存、预约核销、账号或园艺人员。

植物档案采用植物本身底色与外层标题的撞色墨水，保留「农科枝报」报头、植物图版和纸张颗粒，删除植物旁的装饰刻度线。层级收拢为植物名与学名、独立图版、简短介绍、枝条来处与照料提示；删除重复口号、重复拉丁文、冗长的简报和示例故事。光照、浇水、扦插改为配有线稿图解的三组栽植札记，手机上图左文右，宽屏为三栏；各植物使用对应的叶形与简短提示，水向介质下渗并从底部排出，入土叶节或枝刺使用指向标记。生长手记保留本机实际记录；没有记录时用「村里修剪 → 驿站整理 → 新家养护」图解说明去向。末尾重新设计为邮单式接收栏，地点和方式分行，单个接收按钮采用双层细线边框。悬停与键盘聚焦时，文字向右、箭头向左水平内收；左右两端分别绘制保持原比例的枝茎、叶柄、叶片和叶脉，叶柄准确连接枝节，以 1px 细线贴合按钮真实边框逐渐生长，叶柄终点与叶片基部共用坐标，取消未绘制描边的端点散点。点击邮票时先平顺收拢当前纸张弯曲与悬停姿态；整张背景印面和文字持续正向放大，文字与齿孔始终不透明，移出视口后才替换为同色平面。植物图层独立运动：先测量报纸中实际图版尺寸，按缓动曲线放大到该尺寸，再沿直线路径轻盈落到实际图版位置，与原图无淡出交接。植物不会继承背景的巨大镜头缩放；放大阶段中心固定，返回时文字液化消失，完整邮票底图、文字和独立植物图层再沿缓动曲线缩回对应邮票。返回液化使用每次重新启动的显式时钟控制位移与消隐，移除依赖 SVG 自动计时的偶发失效。缩回时直接移动常态邮票本身，提前准备并暂停同一组纸面切片；取消额外悬停、抬升和二次回落。转场与常态邮票共用相同的视口镜头，缩小结束前已恢复常态曲面；植物在相同位置叠合，原纸面移回原卡位后继续悬浮与风动，投影沿原时钟自然伸展，不在交接帧重建切片或换成另一张印面。邮票肌理作为同色纸底上的独立叠层，随放大反向补偿颗粒尺寸并逐渐收走，不再放大成粗颗粒满屏底图；缩回时以同一频率重新叠回细肌理。进出时间略微放缓。进入报纸时，首屏范围内文字已完整印好，不再逐字出现；首屏以下的正文仍随滚动显墨。转场支持 Esc 取消、章节离开清理与减少动态效果；删除报纸底部的刊尾文字；接收后，按当前画布全宽、全高和可见阅读位置搭建真实报纸正反两面，包含透明导航后的顶部纸面，不再从导航下方裁切，仅沿横向中缝慢慢对折一次，以原尺寸向上收走；背面独立设计为「栽植手帖」，以植物小标本、给下一枝的寄语、光水根三栏和驿站落款组成完整折页，不再复制正面或当前文章；删除模拟横线与内栏缩小，折影仅保留轻柔接触边。记录点入时的滚动位置，报纸、场景背景和邮单机共用当前植物的纸色与墨色，机体到位才开始出纸。

领取流程采用「邮单机出票」：报纸完成折叠后，与当前报纸同色的邮单机始终从屏幕上方滑入，使用未受滚动偏移影响的机体位置计算起点；采用哑光外壳、窄出纸槽与固定压纸唇，移除高光、螺钉圆点、品牌大字及外部返回文字，机体右上角叉号可关闭并返回植物档案，草稿保留。米白长邮单沿出纸口的同一轨道滑出，机体落定前纸张保持在滚轮之后；页首采用全宽标题、下方植物信息与邮票并排的版式，名称、编号和来源层级清晰。邮戳使用红色套印圆环、细颗粒缺墨及微小浮雕阴影；纸张使用居中的柔和边影，接缝阴影归属于随机器移动的压纸唇，删除出纸区域固定的阴影伪元素，机体退出不再留下横影；移除硬偏移大投影。删除重复英文、装饰编号和冗余提示，正文、选项与按钮按手机阅读放大，步骤缩为信息、方式、约定、邮单四个清晰标签。首屏范围内文字已印在纸上，随纸的前缘向下推出；取消整张纸出完后再出现文字，后续未进入首屏的栏目才随滚动逐字显墨。步骤切换只推出填写区，不反复播放整张纸的出票；选择时在方框或选定章上落印。签单和确认领取先落下对应印章，再回到取票口，按整张纸的实际高度向上回收，随后沿同一滚轮轨道推出已印好字的新凭证；新凭证在滚轮下方撕离，机体向上撤走，邮单保留在画布上，右上角出现收藏关闭按钮。关闭已签邮单时，纸张从下向上卷起成纸卷，再从画面右侧收走。修改和到站盖章时可重新接回滚轮，再回收并打印。未签单关闭时，先回收纸张，再撤走机体；随后推出折叠报纸并打开，恢复点入时的阅读位置。返回、修改与草稿继续保留。领取页已移除演示、模拟等可见标签，状态文案改为本机邮单已生成和待到站领取；保留线下自取说明及实际安排以驿站确认为准的提示。「我已到站领取 · 盖章」由用户确认自己的领取情况，盖章后加入枝条放映室。新增的 claim-press.js 管理出纸、滚动显字、减少动态效果及清理，claim-postal.css 仅影响领取流程；所有草稿与记录仍在浏览器，不连接真实库存或现场核销。

初始邮册中的紫薇领取记录、明信片和社区问答均为明确标记的演示数据。领取邮单中的二维码图形只承担视觉占位，不可用于核销；图形采用 21×21 模块、三组定位方框、时序点和四模块留白边，按邮单编号稳定生成，并非有效扫码凭证。

枝条放映室采用铺满视口的曲面 CRT 画面，没有机壳或屏幕外框。玻璃边缘暗角、径向鱼眼位移、扫描线、磷光栅格、缓慢摩尔纹、噪声和轻微同步干扰共同形成电视质感。顶部章节导航与所有页面共用同一组坐标，并沿内容左右边界展开；节目选择改为养护、近况、档案三枚等宽、纵横居中的 OSD 屏显按键，删除重复序号，删除原生下拉框和装饰圆盘，三个节目为养护放映、生长回放、植物档案，自动播放入口与定时切换均已删除。底部是固定中针的循环植物刻度，08 后接 01，支持点击、键盘方向键、Home/End、滚轮和带轻微惯性的拖动；相邻刻度虚拟循环排列，选中植物始终回到中央。切换植物和节目时，内容先以约 300ms 的轻微横向剪切与最高 6px 的噪声位移产生波纹扭曲，仅末段退出，再逐字呈现新文字；删除反复闪断和强错位残影，任何章节进入放映室时，先以约 720ms 的 CRT 关机光幕收走前一章，替代该章节原本的退场；放映室离开时也使用同一光幕。画面以视口中心裁切收为细线，不缩放挤压文字，滚动较长的档案或邮单也以当前视口为基准。进入时接入柔和的灰绿色待机底，再以约 1140ms 的连续裁切展开完整电视画面；文字、图形与屏幕纹理一起展开，背景不再提前变成浅绿色纯色层。开屏前即安装逐字与线稿描画，展开时已经有实际节目内容，避免完整内容先闪现再重新打字。离开放映室时，以目标章节的真实底色承接收屏，不经过深色待机底；包含邮票馆、来信、植物档案、邮单与生长明信片。快速切换会清理旧光束、遮罩与动画，减少动态效果时直接呈现内容。养护条目切换时，下方文字与图示一起轻微波纹扭曲，图示通过逐条描画的线稿遮罩慢慢显现，再进入对应的独立循环场景：柔和光线持续到达叶面、水分沿土层向下渗透、固定枝段、观察叶节与耐心等根；骨架始终保留，流动虚线按完整节距循环，首尾同相，不再淡出根系重播。每个场景保留植物、遮光设施、水滴、介质、工具与时钟等动作图形，并在图内上方设置两条简短说明与独立细引导线，文字按实际屏幕尺寸统一为 14px；注释与动作图形分区留白，引导线指向真实部件并在接近物体处留出间隙。继续删除图下小字，无位图植物或多个主题混放；每次只有一种场景，无花盆，八种植物各有三条不同的提示，并绘制对应的 24 个独立矢量场景。各场景按图形实际边界和注释区加留白自动取景，在放映区居中；移除木槿太阳后方的装饰轨迹与重复地线，遮光网和柔光棚补足相连的支撑，叶脉按各自叶形绘制且不越出叶片；湿度探针刻度连接探针本体，放大镜内分别绘制枝皮与介质颗粒，不使用悬空刻度或折线图代替结构；轮廓描画与填色分层，填色随描画柔和渐进，不再在描边遮罩撤销时突然出现。浇水场景补足枝条，保留光流、渗水、排水与空气流动方向；正文和操作按键在画面下方统一排版，短屏竖向可滚动。场景包括：如金叶女贞检查表土、小叶女贞区分新芽与新根、六月雪维持湿度、木芙蓉减少大叶负担、桂花稳定环境与耐心等根、贴梗海棠辨认枝刺。各场景分别使用窗帘、遮光网、柔光棚、表土探查、空气孔隙、排水路径、枝段固定、放大观察与时钟等与内容相关的线稿。枝干、叶片和叶节使用同一局部坐标，剪刀两臂共用真实转轴；遮光网网条限制在框内，手指触点不穿过土面，水流沿介质向下、余水从底部排出。新芽场景保留根部问号，避免把新芽画成已生根；连续流线按完整虚线节距循环，转轴与骨架不随动作漂移。24 个场景均核对图形居中、SVG 范围和手机端切换。养护采用绿色磷光底与暖锈色矢量，近况采用蓝绿屏色、影像取景框、日期和回放说明；尚无影像时显示单色电视测试卡，档案采用植物图版、名称与资料表；档案采用完整植物图版，植物居中展示，中文名与学名统一放在图下；删除孤立的图版数字及其半截横线，编号只保留在资料栏。手机端下方为通栏介绍与资料行，电脑端资料位于图版右侧。两组 OSD 按键进行文字光学校正，养护条目按钮删除数字；难度栏采用上方粗标签、下方细内容，与左侧名称保持相同的阅读层级。切换中发生变化的植物名、英文学名、难度、频道号、正文与动画说明均逐字呈现，不变的字段不重播；SVG 标注使用 tspan 保持矢量排版。养护正文取消固定留白，重新调整标题、正文与主题按键的距离。手机端增大难度信息、养护正文、图中说明与刻度字号；难度标注明确归属于当前植物，下方养护区上移，删除近况页重复的领取后开启记录、生长记录小字和底部英文副标。正文与按钮不施加常态曲面位移，只弯曲图示区域，保证对齐与可读性。所有入口继续连接原来的领取、档案与生长明信片。系统减少动态效果时停用曲面位移、环境动效及打字转场。

枝友来信改为浅灰绿画布上的独立打开信封，自然竖向循环浏览，取消收信盒侧壁与信件堆叠，预设 10 封覆盖八种植物的演示来信；相邻信封缩短到约 44–76px 的间距，不再强制每屏一封；首屏与收信后完整展示当前信封；滚动区域贯穿画布，不再有导航和工具栏之间的内部裁切窗口。植物图版在信纸与信封前片后方，信纸露出植物话题、称呼和来信主题。使用内置 image_gen 生成的透明纸张素材 `dist/assets/letter-pocket-paper.png` 表现真实纤维、折痕与纸边，提示词记录在 `docs/letter-envelope-generation.md`。底部 56px 高的完整胶囊搜索栏包含搜索、规范滑杆筛选图标与写信；筛选弹层从底部连续展开、收起，使用植物选项按钮，可与回信状态组合检索，支持空结果重置。信封与工具栏保持不透明，从画布下方错时滑入。滚轮采用带缓冲的连续滚动，鼠标拖动释放后沿速度惯性滑行，触屏保留原生惯性；循环回收同步校正惯性目标，点击抽信、筛选、切章时停止旧惯性。点开时先滚动居中，再沿同一位置抽出已露出的信纸，再展开完整正文；关闭时撤去中性色罩，回插原信封并保留居中后的滚动位置。支持照片、回信与本地寄信，新信返回列表并定位。顶部使用原网站同一导航与墨绿字体，正文与功能保持可读手机尺寸。写信页仍为端正信纸，正文18px；所有信件仅存在当前浏览器。

## 植物插画

`dist/assets/` 当前包含金叶女贞、木槿、小叶女贞、紫薇、六月雪、木芙蓉、桂花、贴梗海棠 8 幅独立植物插画。紫薇、桂花沿用原图，另外 6 幅使用内置 imagegen 工具生成，并通过同一工具处理透明背景；最终以保留透明度的 WebP 格式存放于项目。提示词按物种分别描述叶序、叶形、花色和枝条构图，统一要求细密植物图鉴插画、轻微丝网质感、透明背景、无文字边框和投影。邮票的齿孔、名称与编号由页面代码绘制。

首页上方为植物名称和衬线斜体英文学名，下方为每种植物独有的短句与说明。中央邮票以视口的横纵 50% 定位，上下中文大字共用字号，上方保留留白，下方额外补偿约 16–25px 的投影空间，以视觉间距为准；下方说明采用与英文学名呼应的衬线斜体。八种浅色背景分别配莓红、石油蓝、紫、绿等互补色大字，小字使用对应的较深同色墨水。植物名保持原有墨色，字形和基线完全固定；章节进入时中央邮票在原位以约 1.44 秒的交错笔刷遮罩涂抹显现，实际印面、植物和纸张风动共用同一遮罩，影子在印面描完后自然伸展；左上邮票从下方、右下邮票从上方画布外进入，全程不透明，两侧统一晚 0.18 秒启动、持续 1.32 秒，中央先入场。进场约 0.74–0.78 秒起，上下中文固定在原位，使用逐字描写的墨迹遮罩，文字在邮票落定前开始出现；英文和说明随后逐字显墨。书写完成后无缝恢复原字，字号、字宽和基线保持一致，首次进入也不再上滑。普通退场时文字收墨，中央邮票向下回收、轻微向后翻离，两侧沿原路径离开，中央邮票不再放大；进入放映室时则由统一的 CRT 关机光幕接管。切换放慢至约 1.12 秒，文字沿固定水平基线不透明地进出，文字与邮票使用隔离的平面图层，确保文字始终被邮票遮挡。中央邮票始终居中，左上邮票下移、右下邮票上移，宽屏也只在两边露出邮票边角。邮票保持端正，抽换时只有轻微纵深。中央邮票悬停时缓缓放大 1.2%，在原位随指针进行约 ±4.5° / ±5.5° 透视倾斜；恢复仅中央邮票的指针位置柔和泛光，保留缓慢放大与三维倾斜，整张亮度滤镜仍禁用；中央邮票使用 20 条切向拼接的原版印面，在约 7.2 秒一轮的风动中让局部鼓起的波峰从右侧向左侧连续掠过，经过后回平，保留原始插画、排字与齿孔，不使用整张旋转代替纸面形变，两侧邮票保持静止且没有悬停特效。独立投影持续播放水波，悬停、离开和切换都不重启时钟；右下投影仍保持相同的横纵偏移。邮票叠加细颗粒与纵向纸纤维，场景保留低强度胶片噪点、径向鱼眼和边缘透镜感。系统减少动态效果时停止墨色呼吸、纸面风动、噪点、水波及跟随，文字与操作仍可直接使用。

navigation.css 统一管理全部页面的章节坐标：左、中、右三个章节共享同一套网格，移除宽屏额外品牌块；首项文字到视口左边与上边使用相同距离，导航字体保持米白且无投影。当前章节仍用常驻的细线括框表示，切换时括框连续移动。返回邮票馆前预先铺好当前植物背景，鱼眼贴图解码后启用，避免露白或滤镜首帧空缺。导航透明，全站隐藏可见滚动条。

当前目录的模拟记录使用 `next-branch-demo-v2` 浏览器存储；升级时只导入仍在本系列的植物记录，原 `next-branch-demo` 数据保持保留，以便找回旧版演示记录。

放映室养护内容使用现有演示资料，并参考 [RHS 软枝扦插指南](https://www.rhs.org.uk/propagation/softwood-cuttings)、[RHS 木槿资料](https://www.rhs.org.uk/plants/40530/hibiscus-syriacus/details)、[NC State 金叶女贞资料](https://plants.ces.ncsu.edu/plants/ligustrum-x-vicaryi/)、[NC State 六月雪资料](https://plants.ces.ncsu.edu/plants/serissa-japonica/)、[NC State 木芙蓉资料](https://plants.ces.ncsu.edu/plants/hibiscus-mutabilis/)与[NC State 贴梗海棠资料](https://plants.ces.ncsu.edu/plants/chaenomeles-speciosa/)。文案区分未生根枝条与长稳后的植株，不承诺具体生根时间，实际剪取与扦插操作以驿站指导和枝条情况为准。
